# Model Evaluation Report

## Dataset

- **Name**: UCI SMS Spam Collection
- **Size**: 5,574 messages
- **Classes**: spam (13.4%), ham (86.6%)
- **License**: CC0 1.0 Universal (Public Domain)
- **Source**: https://archive.ics.uci.edu/ml/datasets/sms+spam+collection

## Training Configuration

| Parameter | Value |
|-----------|-------|
| Algorithm | Logistic Regression |
| Vectorizer | TF-IDF |
| N-gram range | (1, 2) |
| Max features | 10,000 |
| Min document frequency | 2 |
| Max document frequency | 0.95 |
| Class weight | balanced |
| Regularization (C) | 1.0 |
| Max iterations | 1000 |
| Random seed | 42 |
| Test split | 20% |

## Known Limitations

1. **Binary classification only**: Cannot distinguish between spam, phishing, and fraud
2. **SMS domain**: May not generalize to emails, social media, or other text formats
3. **English only**: Trained on English messages only
4. **Temporal drift**: Spam patterns evolve; model may need periodic retraining
5. **Class imbalance**: Ham messages significantly outnumber spam (7:1 ratio)

## Explainability

The system provides explanations based on Logistic Regression coefficients:

- **Top features**: Terms with highest TF-IDF weight × coefficient for the predicted class
- **Direction**: Whether each feature pushes toward spam or ham
- **Disclaimer**: Indicators are learned patterns, not proof of fraud

## Reproducibility

To reproduce the evaluation:

```bash
cd backend
python -m app.ml.train
```

This will:
1. Download the dataset (if not present)
2. Train the pipeline with fixed random seed
3. Evaluate on held-out test set
4. Save metrics to `model_artifacts/evaluation_report.json`
5. Save model to `model_artifacts/fraud_detection_model.joblib`
