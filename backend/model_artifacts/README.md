# Model Artifacts

This directory stores trained model artifacts generated by the training pipeline.

## Files

After running `python -m app.ml.train`, the following files will be created:

- `fraud_detection_model.joblib` — Trained scikit-learn Pipeline
- `evaluation_report.json` — Test-set evaluation metrics
- `training_metadata.json` — Training configuration and metadata

## Model Details

- **Algorithm**: Logistic Regression with TF-IDF vectorization
- **Classes**: ham (legitimate), spam
- **Features**: TF-IDF with unigrams and bigrams (max 10,000 features)
- **Version**: 1.0.0

## Regenerating

To retrain the model:

```bash
cd backend
python -m app.ml.train
```

## Git Ignore

Large model files (*.joblib, *.pkl) are excluded from Git. Only the README
and evaluation reports are committed.
